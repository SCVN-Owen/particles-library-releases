# Particles Library: bản cài cho Mac

**Tải bộ cài (~1 MB):** [Particles-Library-Installer.dmg](https://github.com/SCVN-Owen/particles-library-releases/releases/latest/download/Particles-Library-Installer.dmg)

1. Mở file DMG, chạy **Particles Library Installer**.
2. Lần đầu macOS có thể chặn vì app chưa được Apple ký: vào **System Settings › Privacy & Security**, bấm **Open Anyway**.
3. Bộ cài tải app vào thư mục Applications rồi mở. Lần sau mở bộ cài, nếu app đã có thì nó mở app luôn.

App tự báo khi có bản mới (nút **⬆ Cập nhật** ở thanh trên cùng). Cần Mac chip Apple (M1 trở lên).

Repo này chỉ chứa các bản phát hành; mã nguồn nằm ở repo riêng.
